# Student Management System

## Deskripsi
Student Management System adalah program sederhana berbasis Java yang digunakan untuk mengelola data mahasiswa, termasuk penambahan, pencarian, dan tampilan daftar mahasiswa.

## Fitur
- **Tambah Mahasiswa**: Menambahkan mahasiswa baru ke dalam sistem.
- **Cari Mahasiswa**: Mencari mahasiswa berdasarkan NIM.
- **Tampilkan Semua Mahasiswa**: Menampilkan daftar mahasiswa yang tersimpan.
